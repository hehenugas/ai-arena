# Pocket World

Pocket World is a self-contained Three.js diorama: a small floating island with a house, pond, trees, windmill, clouds, rain, and connected environment controls.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (the project defaults to port `5178`).

## Verify a production build

```bash
npm run typecheck
npm run build
npm run preview
```

Everything is generated in code and runs in the browser without a backend, remote textures, model files, or API keys.
